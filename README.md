# 八仙双人桌宠

一个双角色互动桌宠：吕洞宾和钟离权会常驻桌面、透明悬浮、自由拖动，并通过快捷键切换动作组。

## 已做功能

- 透明悬浮窗口
- 只允许运行一个桌宠实例；重复点击图标会显示已有桌宠，不会再出现一组
- 透明空白区域允许鼠标穿透，不影响操作后方窗口
- 吕洞宾、钟离权双角色同屏
- 待机时，两人分别随机播放“睁眼、闭眼、睁大眼”动作
- 待机时点击任意人物，会随机显示关心、害羞、惊讶、生气或委屈表情，并说出与表情对应的台词
- 吕洞宾害羞时不说话，只会冒出爱心
- 安静待机一段时间后，两人会从九组小聊天中随机对话，并逐句切换待机、开心、嫌弃、关心、害羞、惊讶、生气或委屈表情
- 吕洞宾使用红色气泡，钟离权使用蓝色气泡；人物脚下不再显示姓名标签
- 将两人拖得很远时，钟离权会呼喊“师弟，你在吗？”，吕洞宾会回应“钟离权？钟离权！”
- 将两人拖近时，自动播放靠近动作，再切换为双人贴贴并出现爱心
- `F7`：切换到待机组
- `F8`：切换到双人对话组；点击吕洞宾后，两人靠近并开始对话：
  - 吕洞宾：在蓬莱假扮神仙是什么罪？
  - 钟离权：死罪~
- `F9`：切换到单独说话组；分别点击角色触发各自台词：
  - 吕洞宾：苍生我要救，钟离权我也要救。
  - 钟离权：骗术的最高境界，就是瞒天过海。
- 两个角色都可以在整个桌面范围内上下左右拖动
- 右键菜单：置顶、放大、缩小、重置位置、躲一下、退出

## 本地运行

先安装 Node.js。然后在这个文件夹里运行：

```bash
npm install
npm start
```

如果使用 pnpm：

```bash
pnpm install
pnpm start
```

如果使用 pnpm 时提示需要批准构建脚本，可以运行：

```bash
pnpm approve-builds --all
pnpm install
```

如果 Electron 下载失败，通常是网络到 Electron 下载源不稳定；换一个网络后重新运行安装命令即可。

## 打包给别人用

Windows：

```bash
npm run dist:win
```

macOS：

```bash
npm run dist:mac
```

## GitHub 自动构建 macOS 通用版

项目包含 `.github/workflows/build-macos.yml`。将项目上传到 GitHub 后：

1. 打开仓库的 `Actions` 页面。
2. 选择 `Build macOS DMG`。
3. 点击 `Run workflow`。
4. 构建完成后，在该次任务页面的 `Artifacts` 区域下载 DMG。

推送以 `v` 开头的标签（如 `v0.7.0`）时，工作流还会自动创建 GitHub Release 并附上 DMG。当前配置生成一个同时支持 Intel 与 Apple Silicon 的 universal 安装包。未配置 Apple 开发者证书时，成品不会签名或公证。

Linux：

```bash
npm run dist:linux
```

生成的安装包会在 `release` 文件夹里。一般需要分别在对应系统上打包：Windows 打 Windows 包，macOS 打 macOS 包，Linux 打 Linux 包。
